# Switchback in the terminal

`switchback` opens the same chat in your terminal. With the extension and the terminal both open in a workspace, they share one engine, so a session started in one shows up live in the other.

- `switchback --resume` picks up a saved session.
- `switchback run "fix the failing test"` runs one turn for scripts and CI.
- `switchback doctor` shows your configuration and checks every model.
