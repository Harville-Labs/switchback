# 0014: Open-core licensing

**Status:** Superseded by [0020](0020-private-console.md) · 2026-10-01

## Context

Switchback was proprietary, and the plan for selling it (#31) was per-seat license keys enforced inside the CLI. We now want anyone to install and use Switchback on their own, free, from a public repository. What companies pay for is managing it for a team: the hosted sites at switchback.harville.ai ([ADR 0010](0010-hosted-sites.md)), with seats, policy, usage, and single sign-on.

## Decision

- Everything except `apps/site` is licensed under the **Apache License 2.0**: the CLI, the engine, the protocol, the client, the providers, the router, and the VS Code extension. Apache-2.0 includes a patent grant, is accepted by company legal reviews, and grants no rights to the Switchback name or marks. `LICENSE` holds the license text and `NOTICE` names the exception.
- `apps/site` stays **proprietary** (`apps/site/LICENSE`). Its code is public so customers can see how the service treats their data, but it may not be run or offered as a service without an agreement with Harville Labs.
- The CLI never checks a license. Individuals use Switchback free. Companies pay for a site, and the site enforces its seats, not the client.
- Contributions to the Apache-2.0 parts are accepted under Apache-2.0 (its section 5); no contributor license agreement. Harville Labs alone develops `apps/site`.
- Releases ship `LICENSE`, `NOTICE`, and `THIRD-PARTY-NOTICES.txt`, generated by `scripts/third-party-notices.ts` from exactly what the bundler includes. Each `.vsix` carries its own copy.

## Consequences

- Code in an Apache-2.0 package must not import from `apps/site`. The site may depend on the open packages (it validates policy with the engine's schemas), never the reverse.
- Anyone may fork and redistribute the CLI and extension, but the hosted service, its data, and the brand remain the product.
- The paid surface is sites. Features for teams belong there or behind organization policy ([ADR 0007](0007-organization-policy.md)), which works with any compatible server.
- Bundled dependencies keep their own licenses. Each new runtime dependency's license must allow redistribution in the binary; the notices script fails a release if a package declares no license.
